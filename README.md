# 📊 Student Bunk Prediction Model (75% Attendance Criteria)

An ML-based project that **predicts the number of lectures a student can safely bunk** for each subject and in total, while still meeting the **75% attendance requirement**. It also estimates the **overall attendance outcome** for the semester.

## 🧠 Project Overview

This model helps students and academic advisors by:
- Predicting how many **classes a student can miss** per subject
- Checking if the student is likely to **meet the 75% criteria**
- Providing a **semester-level prediction** for attendance status

## 🎯 Key Features

- 🧮 Calculates bunk availability per subject
- 📅 Aggregates data for total semester attendance
- ✅ Predicts final status (Safe to bunk / At Risk)
- 🔢 Accepts data like total lectures, attended lectures, subject names
- 🛠️ Built using **Machine Learning models** for pattern recognition and forecasting

## 🛠️ Tech Stack

- **Python**
- **Pandas, NumPy** – Data manipulation
- **Scikit-learn** – ML model training & prediction
- **Matplotlib** –  Visualizations
